# Gmail MCP (personal use)

Gmail MCP is a small personal tool used by a single person, its owner, to read and manage his own Gmail mailbox from AI assistants such as Claude Desktop, through a local MCP (Model Context Protocol) server.

## What it is

- A local server that runs only on the owner's own computer.
- It talks to the Gmail API using an OAuth client created in the owner's own Google Cloud project.
- It is **not** a public service. There is no website, no hosted backend and no other users.

## What it is not

- It is not offered to third parties.
- It does not run on any server operated by the owner or by anyone else.
